# Estructura de la web

Reorganització del 5 de novembre de 2026.

## Navegació pública

Inici, Serveis, Casos d’èxit, Equip i Contacte.

## Ceràmica Riu Sec

- El projecte: encàrrec, objectiu, abast, estat, empresa, estratègia, missió, visió i organització.
- Procés actual: imatge AS-IS facilitada per Héctor i les huit activitats amb responsables, documents, eines, deficiències i conseqüències.
- Proposta de millora: quatre categories, model TO-BE, anàlisi completa de les huit activitats, decisions del recorregut, prioritats i indicadors.

Sense índex lateral ni pestanyes internes en aquestes tres pàgines. Les ampliacions llargues s’obrin en el mateix lloc. L’empresa i el diagnòstic antics redirigeixen al contingut integrat, mantenint els enllaços anteriors.

Requisits ERP i Documents i fonts continuen amagats amb `showAdvancedSections = false`. Només es recuperen quan Héctor ho demane.

## Criteris de lectura

Una sola capçalera principal per pàgina, columnes amb amplària suficient, mida de text llegible i cap retall de text o altura fixa per a paràgrafs. La imatge AS-IS i el BPMN TO-BE es mostren complets inicialment, amb ampliació i descàrrega.
